# 开发说明

## 程序

`src/Settings.cs` 保存不可变参数快照，`src/Mixer.cs` 实现按采样调度的单位混音器，`src/FlakASMR.cs` 包含程序与诊断入口。`src/WasapiEngine.cs` 是持续运行的 WASAPI shared-mode 输出。`src/PixelForm.cs` 包含点阵文字绘制、命中区域、鼠标与键盘输入。程序只引用 Windows / .NET Framework 系统库。

`build.ps1` 从项目内资源构建 `dist/RA2FlakASMR.exe`；没有构建时下载步骤。`test.ps1` 是本地和 CI 的共同检查入口。

## 最新原型

用 diagrams.net / draw.io 打开 `design/RA2FlakASMR.drawio`，包含暂停、播放和交互三态三页。SVG 也包含可编辑结构及内嵌字体。运行时用原始点阵数据绘字，不依赖用户安装字体。

设计基准：

- 逻辑窗口 300×208，标题栏按钮与加减按钮均为 20×20。
- 按钮间距 4 px，左右对齐线 x=10 / x=290。
- 音量数值框左边沿 x=246，与右列减号对齐。
- 图标顶部 y=36，音量区底部 y=196，相对内容框顶部 y=32 / 底部 y=200 留白相等。
- 输入框和按钮间的间距，以及正常 / 悬浮 / 按下状态，均由像素坐标确定。

修改 draw.io 本身不会自动修改程序命中区域。要同步修改应用界面，应修改 `tools/ui_scene.py` 与 `src/PixelForm.cs` 中对应的几何常量，再重新生成资源、参考图并测试。

## 重新生成设计与资源（可选）

普通构建不需要 Python。只有修改资源时才需要 Python 3.10+ 及 `tools/requirements.txt` 的依赖：

```powershell
python -m pip install -r tools/requirements.txt
python tools/export_design.py
python tools/prepare_assets.py
./build.ps1
./test.ps1
```

`ui_scene.py` 保存最终场景，没有历史版本依赖。`pixel_font.py` 读取 `assets/fonts/WestwoodImprovedFont/game.fnt`。预生成的 TTF 供 SVG / draw.io 使用，`westwood.bin` 保存运行时用到的 95 个 ASCII 字形。图集由原始像素组成，显示时使用最近邻整数放大。

音效原件放在 `assets/audio/original/`。需要重新生成 PCM 时运行：

```powershell
python tools/convert_audio.py
./build.ps1
./test.ps1 -Device
```

转换会去除 DC 偏移、转为 48 kHz 单声道 16-bit PCM，并处理首尾淡化和峰值。构建实际嵌入 `assets/audio/*.wav`，不会在运行时解码 OGG。

## 验证

自动检查包含八个音效的零边界、间隔分布、64 单位高频混音、限幅、数量移除、暂停与 50 次启停，以及点击 / 数字输入 / 拖动和布局命中。暂停和播放画面均与 `docs/images/` 中参考图逐像素对比。

交互检查覆盖两列标准差的动态上限、降低均值时的原子截断、参数快照的防御性约束，七个数值编辑器内的空格确认并切换播放，以及标题栏捕获拖动期间的空格响应。移动本身不发布音频参数。逻辑画布和物理尺寸缓存均与强制全量重绘逐像素比较；音量图集检查轨道三态相同，滑块保留凹边。

CI 交互检查用 `--no-device` 模式，不要求 GitHub runner 有音频设备。`-Device` 额外在本机以零主音量执行 WASAPI 输出测试。

`-Device` 同时执行 `--notification-test`：故意用未注册到 WASAPI 的事件句柄等待，屏蔽全部设备通知，从实际的超时路径补入音频；检查每秒帧数和空缓冲。正常运行始终等待注册的设备事件。诊断中的 `fallback polls` 是短超时后检查缓冲的次数，不代表发生断声。

`RA2FlakASMR.exe --soak-test <日志路径>` 运行 60 秒真实设备持续测试，配置为两列 10/500/100、零主音量，检查供数总量、空缓冲及错误，并记录帧数进展间隔。`--self-test` 中的 600 秒 PCM 连续性测试使用 30% 音量，独立验证生成的声音没有长段整体归零。

`tests/ReferenceMixer.cs` 固定保存优化前的算法，只编译进独立测试工具，不进入发布 EXE。CI 使用四种音频块大小，将新旧混音器产生的约 461 万个 PCM 样本逐一比较，允许最多 1 LSB 的平台浮点舍入差异，并核对开火次数。

运行 `./tools/benchmark.ps1` 查看计算耗时；加入 `-Live` 会同时测量真实音频输出与界面消息响应，主音量为零。优化算法、数学推导和本次基准记录见 [性能说明](性能说明.md)。

加入 `-Drag` 测量 20 单位的持续捕获拖动和完整画面复制，也可直接运行 `RA2FlakASMR.exe --drag-benchmark <日志路径>`。窗口保持屏幕外，通过应用自己的鼠标处理函数驱动移动，不注入全局鼠标事件；因此结果不能替代对实际桌面拖动帧率的观察。
