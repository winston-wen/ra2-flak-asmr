# 开发说明

## 程序

`src/FlakASMR.cs` 包含不可变参数快照、按采样调度的单位混音器和诊断入口。`src/WasapiEngine.cs` 是持续运行的 WASAPI shared-mode 输出。`src/PixelForm.cs` 包含点阵文字绘制、命中区域、鼠标与键盘输入。程序只引用 Windows / .NET Framework 系统库。

`build.ps1` 从项目内资源构建 `dist/RA2FlakASMR.exe`；没有构建时下载步骤。`test.ps1` 是本地和 CI 的共同检查入口。

## 最新原型

用 diagrams.net / draw.io 打开 `design/RA2FlakASMR.drawio`，包含暂停、播放和交互三态三页。SVG 也包含可编辑结构及内嵌字体。运行时用原始点阵数据绘字，不依赖用户安装字体。

设计基准：

- 逻辑窗口 300×208，标题栏按钮与加减按钮均为 20×20。
- 按钮间距 4 px，左右对齐线 x=10 / x=290。
- 音量数值框左边沿 x=246，与右列减号对齐。
- 图标顶部 y=36，音量区底部 y=196，相对内容框顶部 y=32 / 底部 y=200 留白相等。
- 输入框和按钮间的间距，以及正常 / 悬浮 / 按下状态，均由像素坐标确定。

修改 draw.io 本身不会自动修改程序命中区域。要同步修改应用界面，应修改 `tools/ui_scene.py` 与 `src/PixelForm.cs` 中对应的几何常量，再重新生成资源、参考图并测试。

## 重新生成设计与资源（可选）

普通构建不需要 Python。只有修改资源时才需要 Python 3.10+ 及 `tools/requirements.txt` 的依赖：

```powershell
python -m pip install -r tools/requirements.txt
python tools/export_design.py
python tools/prepare_assets.py
./build.ps1
./test.ps1
```

`ui_scene.py` 保存最终场景，没有历史版本依赖。`pixel_font.py` 读取 `assets/fonts/WestwoodImprovedFont/game.fnt`。预生成的 TTF 供 SVG / draw.io 使用，`westwood.bin` 保存运行时用到的 95 个 ASCII 字形。图集由原始像素组成，显示时使用最近邻整数放大。

音效原件放在 `assets/audio/original/`。需要重新生成 PCM 时运行：

```powershell
python tools/convert_audio.py
./build.ps1
./test.ps1 -Device
```

转换会去除 DC 偏移、转为 48 kHz 单声道 16-bit PCM，并处理首尾淡化和峰值。构建实际嵌入 `assets/audio/*.wav`，不会在运行时解码 OGG。

## 验证

自动检查包含八个音效的零边界、间隔分布、64 单位高频混音、限幅、数量移除、暂停与 50 次启停，以及点击 / 数字输入 / 拖动和布局命中。暂停和播放画面均与 `docs/images/` 中参考图逐像素对比。

CI 交互检查用 `--no-device` 模式，不要求 GitHub runner 有音频设备。`-Device` 额外在本机以零主音量执行 WASAPI 输出测试。
