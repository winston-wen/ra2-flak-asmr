# 使用说明

双击 `RA2FlakASMR.exe`。默认处于暂停状态，点击标题栏的播放按钮或按空格开始无限播放。暂停按钮平滑淡出；关闭按钮淡出后退出；最小化后继续播放。

## 两列参数

左右两列各控制一组单位。同一列内的两张单位图标共用这一列的参数。

| 参数 | 含义 | 范围 | 默认值 |
| --- | --- | --- | --- |
| Number | 同时工作的单位数量 | 0–32 | 左 2，右 3 |
| itv (ms) | 每个单位的平均开火间隔 | 50–10000 ms | 500 ms |
| std (ms) | 开火间隔标准差 | 0–5000 ms | 50 ms |
| Volume | 总音量 | 0–100% | 30% |

各单位独立调度，间隔按正态分布随机变化，最低限制为 50 ms。标准差为 0 时采用固定间隔。数量为 0 可关闭对应组。

点击加减按钮，Number 每次变化 1，itv 每次变化 10 ms，std 每次变化 5 ms。按住可连续调整，滚轮也可调整当前行。点击数值可直接输入，超过范围的输入会限制到最近边界。

## 音量与键盘

拖动底部横向滑块，或在音量区滚轮调整；点击右侧百分比可直接输入 0–100。音量调整会平滑过渡。程序不修改系统总音量。

| 操作 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停（未编辑数值时） |
| Tab / Shift+Tab | 按顺序进入下一个 / 上一个数值 |
| Enter | 确认输入 |
| Esc | 取消输入 |
| 编辑时 ↑ / ↓ | 按当前参数步长调整 |
| Ctrl+A / C / V | 全选 / 复制所选数字 / 粘贴整数 |
| Ctrl+↑ / ↓ | 总音量每次增减 5% |
| F1 | 查看字体署名和许可 |

拖动标题栏空白处移动窗口。播放和暂停按钮用凹陷状态表示当前选择；悬浮只改变背景明暗，不移动字形。设置在本次运行中生效，重新打开恢复默认值。

## 没有声音时

确认已点击播放、至少一组 Number 大于 0，且 Volume 和 Windows 音量合成器内本程序音量均大于 0。程序使用启动时的 Windows 默认输出设备；切换或移除设备后若出现错误提示，重新打开程序。

所有音效均已内嵌，不需要将原始音效文件放到 EXE 旁边。
