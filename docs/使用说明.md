# 使用说明

双击 `RA2FlakASMR.exe`。默认处于暂停状态，点击标题栏的播放按钮或按空格开始无限播放。暂停按钮平滑淡出；关闭按钮淡出后退出；最小化后继续播放。

## 两列参数

左右两列各控制一组单位。同一列内的两张单位图标共用这一列的参数。

| 参数 | 含义 | 范围 | 默认值 |
| --- | --- | --- | --- |
| Number | 同时工作的单位数量 | 0–32 | 左 2，右 3 |
| itv (ms) | 每个单位的平均开火间隔 | 50–10000 ms | 500 ms |
| std (ms) | 开火间隔标准差 | 0–min(itv, 5000) ms | 50 ms |
| Oil Derrick | 油井数量 | 0–32 | 0 |
| Volume | 总音量 | 0–100% | 30% |

各单位独立调度，间隔按正态分布随机变化，最低限制为 50 ms。标准差为 0 时采用固定间隔。数量为 0 可关闭对应组。降低平均间隔时，超过新均值的标准差会同时截断；提高均值不会自动提高标准差。

所有单位首次开火都独立随机分散在 0 到该列平均间隔之间，不固定让某个单位立即开火。暂停后恢复、新增单位也采用随机起步；新增单位不会重排正在开火的其他单位。每次打开程序使用不同的随机序列。标准差为 0 时，各单位按固定间隔重复，但仍保留彼此错开的起步时间；调整平均间隔会按比例缩放各自剩余等待时间。

1.2.1 起，两列的炮声分别按原版声音事件批处理，每列最多同时播放 5 个声部。Number 超过 5 仍会增加开火请求的密度；超限时会丢弃本批较晚的请求或替换较早的播放声部，不会排队延迟补播。单位的随机起步和间隔不变。每次发声还按原版随机音高播放：左列 -10% 到 +10%，右列 -5% 到 +5%；基础音量分别为 95%、70%，素材间原有的强弱保留。高音略短、低音略长，但不会改变下一次开火的调度间隔。原版这两组 VShift=0，未额外添加随机音量抖动。

点击加减按钮，Number 每次变化 1，itv 每次变化 10 ms，std 每次变化 5 ms。按住可连续调整，滚轮也可调整当前行。点击数值可直接输入，超过范围的输入会限制到最近边界。

## 油井进账声

Oil Derrick 每次加减 1，也支持点击输入和滚轮。新增油井按占领计入一次 1000 奖励，此后每座每 100 逻辑帧进账 20；本程序采用 60 帧/秒，即约每 1.667 秒付款。一起添加的油井同时付款，后来添加的油井保留各自计时。

所有进账先进入同一个余额，再由全局显示钱数逐步追上余额；显示变化提交 CreditUp 请求，先经过原版独立的声音服务节流；同一服务窗口内的请求合并，再用同一个声道替换旧声。因此增加油井数量会改变计数持续时间与声音节奏，不会按座数叠加 ucredup。

暂停冻结油井和计数器；恢复不会重复占领奖励。减少数量停止被移除油井未来的收入，不扣回已经进账的资金；改为 0 后，尚未显示完的余额仍会完成计数。只想听进账声时，把左右两列 Number 都设为 0。进账声和炮声共用 Volume。1.2.1 另将进账声降低到 1.2.0 的一半，数钱显示与可听节拍的间隔变为原来的 1.25 倍；音高、音效播放速度和油井实际进账周期不变。

## 音量与键盘

拖动底部横向滑块，或在音量区滚轮调整；点击右侧百分比可直接输入 0–100。按下时只有滑块按钮显示凹陷，轨道保持原样。音量调整会平滑过渡。程序不修改系统总音量。

| 操作 | 功能 |
| --- | --- |
| 空格 | 窗口内任意位置获得焦点后播放 / 暂停；编辑数值时先确认输入 |
| Tab / Shift+Tab | 按顺序进入下一个 / 上一个数值 |
| Enter | 确认输入 |
| Esc | 取消输入 |
| 编辑时 ↑ / ↓ | 按当前参数步长调整 |
| Ctrl+A / C / V | 全选 / 复制所选数字 / 粘贴整数 |
| Ctrl+↑ / ↓ | 总音量每次增减 5% |
| F1 | 查看字体署名和许可 |

拖动标题栏空白处移动窗口；开始移动时确认当前输入，拖动中仍可按空格切换播放，Esc 将窗口放回本次拖动前的位置。播放和暂停按钮用凹陷状态表示当前选择；悬浮只改变背景明暗，不移动字形。设置在本次运行中生效，重新打开恢复默认值。

## 没有声音时

确认已点击播放、至少一组 Number 或 Oil Derrick 大于 0，且 Volume 和 Windows 音量合成器内本程序音量均大于 0。程序使用启动时的 Windows 默认输出设备；切换或移除设备后若出现错误提示，重新打开程序。

所有音效均已内嵌，不需要将原始音效文件放到 EXE 旁边。
