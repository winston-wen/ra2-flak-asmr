# 性能优化与验证

本次针对 10+4 单位时的音频与界面卡顿进行优化。测试日期为 2026-10-15；下面是同一台本机、同一构建配置的测量结果，不能直接当作其他电脑的耗时保证。本机旧版在 10+4 / 500 ms 下没有稳定复现主观卡顿，因此保留了真实设备和消息队列诊断入口。

## 基准结果

音频以 48 kHz、1440 帧 / 30 ms 的块处理；表中音频项为单块平均计算耗时，界面项为逻辑画布更新耗时，不包含桌面合成器显示。

| 场景 | 优化前 | 优化后 | 降低 |
| --- | ---: | ---: | ---: |
| 14 单位，500 ms 间隔 | 0.2496 ms | 0.0976 ms | 60.9% |
| 64 单位，50 ms 平均间隔 | 5.5644 ms | 2.6665 ms | 52.1% |
| 从 64 减到 14，稳定后 | 0.4408 ms | 0.0962 ms | 78.2% |
| 长时间暂停后 | 0.3436 ms | 0.0006 ms | 99.8% |
| 交替悬浮加减按钮的画布更新 | 0.4088 ms | 0.0089 ms | 97.8% |

各混音场景测量期间均未触发 Gen0 GC。样本数、P95/P99 和最大耗时保存在 `docs/performance/` 中，极端值可能包括线程被操作系统抢占的时间。

## 混音循环

旧实现对每一个采样点遍历 64 个单位更新增益，再逐一检查所有声部的开始、结束、单位状态。若音频块长为 B，单位槽数 U=64，重叠声部数 V，内层工作约为 O(B·U+B·V)。即使只有少量单位启用，64 槽增益更新仍然发生。

新实现对每个块安排事件，然后按声部连续读取它在当前块中的有效区间，将结果累加到预分配的左右声道数组。声部边界检查只在块外层进行，声部结构也只读取一次。只有正在淡入 / 淡出的单位需要生成逐采样增益；稳定增益 1 和 0 有直接路径。若过渡中的单位数为 A，相关工作约为 O(U+B·A+B·V)，且 V 的循环具有连续的内存访问。

左右声道、包络和声部池在音频流开始前分配。标准音频块处理中没有临时集合、锁、文件访问或托管分配。没有剩余声部时直接写入静音。

## 包络公式与极小数

一阶平滑采用以下递推，t 是目标增益：

```text
g[n+1] = g[n] + (t - g[n]) / τ
       = t + (g[n] - t) · a,     a = 1 - 1/τ
```

在无声部的块中，可用同一递推的闭式一次推进 B 个采样点：

```text
g[n+B] = t + (g[n] - t) · a^B
```

旧版淡出始终趋近零，数值可能在长时间暂停或移除单位后进入 subnormal 区间。现在移除单位的增益小于 1e-5 时归零；这个值与旧版丢弃声部的阈值相同。主增益距离目标小于 1e-12 时取精确目标值，防止无意义的极小数运算，也使稳定状态能使用快路径。

这些阈值不用于跳过正常可听见的淡入淡出。回归测试保留了旧算法，比较采样结果而非仅检查“有声音”。

## 界面更新

原版点阵字形和阴影现在预先生成小位图，数字与百分号在显示窗口前完成缓存。悬浮通常只需更新离开和进入的两个按钮，数值变化只恢复相应输入框，滑块变化只更新音量区域。整幅逻辑画布保留为缓存；重复设置同一个值不再创建参数快照或要求重绘。鼠标在同一控件内移动时也不再反复构造提示文字。

暂停和播放的完整界面仍与确认的原型逐像素相同，字形、配色和布局没有改变。

## 音频调度与诊断

音频线程加入 Windows MMCSS 的 Audio 任务，使用系统提供的 AVRT 接口；基础线程优先级为 AboveNormal。MMCSS 注册失败时保留基础优先级，音频仍可运行。没有修改全局定时器分辨率或系统注册表。参考：[Microsoft MMCSS 文档](https://learn.microsoft.com/en-us/windows/win32/procthread/multimedia-class-scheduler-service)。

诊断记录最大混音耗时、最大服务间隔、音频事件等待超时，以及预填充完成后的空缓冲唤醒次数。空缓冲计数代表可能的供数不及时，不等同于对所有音频硬件或蓝牙链路的爆音检测。

本机一次 8 秒联合测试，在真实 WASAPI 设备上混合 14 个单位，同时持续投递界面消息和修改画布；主音量为零，混音运算保持运行。记录到 519 次界面消息，消息排队 P99 为 1.207 ms，处理与绘制 P99 为 0.117 ms，音频空缓冲和事件超时计数均为 0。原始记录见 `docs/performance/live.txt`。

## 复测

```powershell
./build.ps1
./test.ps1 -Device
./tools/benchmark.ps1 -Live
```

普通 CI 无需音频设备。自动回归测试比较约 461 万个新旧 PCM 样本，覆盖不同块大小、增减单位、间隔分布、音量、声宽、齐射及暂停；本机本次最大差异为 0 LSB，跨平台允许最大 1 LSB 的舍入差异。性能命令的输出放在 `build/performance/`。单 EXE 用户也可通过 `--benchmark <日志路径>` 或 `--live-benchmark <日志路径>` 生成同样的诊断。
